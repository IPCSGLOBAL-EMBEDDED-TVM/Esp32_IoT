# ESP32 & ESP8266 Programming and IoT

This repository contains a collection of practical programs and projects developed using **ESP8266** and **ESP32** for embedded systems, peripheral interfacing, communication, and IoT applications.

The repository is organized into two main sections:

- **ESP8266** – General embedded programming, GPIO control, peripheral interfacing, and communication examples.
- **ESP32** – IoT-focused applications, wireless communication, cloud connectivity, and IoT projects.
